# Contributing

1. Keep every demo value explicitly labelled synthetic unless its public source is verified and cited.
2. Add tests for every planner or validator change, including invalid and infeasible cases.
3. Do not add operational military data, weapon/loadout logic, targeting, combat routing or threat-evasion behaviour.
4. Do not commit secrets or personal data.
5. Update the roadmap only when the stated acceptance test passes.
6. Run `npm test` and `npm run build` before submitting changes.
